# DAY1_MISSION-2_HITMAN-PRIMAASADAFA
Dokumentasi kegiatan workshop

Prima Asadafa

Repository berisi file readme.md yang memuat rangkuman workshop day 1.

Tujuan
1. Memperkenalkan peserta pada platform GitHub sebagai sarana penyimpanan dan pengelolaan dokumentasi secara daring.
2. Melatih peserta membuat dan mengelola repository dengan visibilitas Public.
3. Membiasakan peserta mendokumentasikan materi dan kegiatan selama workshop berlangsung.
4. Meningkatkan kemampuan peserta dalam menyusun catatan dan mengelola file secara terstruktur.
5. Melatih peserta menggunakan file README.md sebagai dokumentasi utama repository.

Rangkuman materi yang disampaikan selama workshop.
Materi dibawakan oleh Nugi Farhan, secara garis besar topik yang dibawakan mengenai AI, Prompting ,dan Git.
Pada awal workshop audience dikenalkann dengan beberapa AI sebagai tools pembantu developing dan Version Control System (VCS).
Lalu juga diajarkan mengenai cara prompting yang baik (Prompt Engineering).
Setelah itu dikenalkan dengan git dan dan github, serta konfigurasi git.
Pada akhir workshop diajarkan implementasi AI untuk pembuatan program sederhana serta AI untuk otomatisasi git.

Poin-poin penting atau pengetahuan baru yang dipelajari saat workshop.
1. Prompt Engineering, sebelumnya saya pribadi belum tahu cara prompting yang baik.
2. Konfigurasi git.
3. Workflow git .
4. Perbedaan antara git dan github.
5. Implementasi AI untuk pembuatan program sederhana serta AI untuk otomatisasi git.

Pendapat pribadi tentang Day 1 Proyek Workshop.
Keseluruhan acara sudah berjalan dengan baik dan narator telah menyampaikan materi dengan baik.
